# Описание проекта

Этот проект представляет собой статический HTML-прототип интерфейса на тему космической отрасли и мониторинга процессов. Основной акцент сделан на визуальную структуру страниц, навигацию по разделам, карточки контента, новости и демонстрацию макетов интерфейсов.

Проект не использует сборщик, backend или frontend-фреймворк. Все страницы открываются как обычные HTML-файлы, а стили и скрипты подключаются напрямую из каталога `dist/`.

## Что есть в проекте

- Несколько вариантов главной страницы.
- Страница новостей со списком материалов.
- Страница отдельной новости.
- Страница раздела "Орбитальные группировки".
- Страница с многоуровневым списком критериев.
- Страница "Ракеты-носители" в статусе заготовки.
- Набор статических изображений, иконок, шрифтов, CSS и JS-библиотек.

## Основные страницы

### `index.html`
Основная главная страница проекта. Содержит:

- фиксированное верхнее меню;
- переключение темы через `data-bs-theme="auto"`;
- большой первый экран;
- карточки/блоки разделов;
- новостной блок;
- нижние служебные блоки и футер.

Это наиболее логичная точка входа в проект. В `info.txt` также указан локальный адрес:

`http://localhost/site/index.html`

### `index-3.html`
Альтернативный вариант главной страницы. По структуре близок к `index.html`, но содержит отличия в контенте и ссылках. Используется как промежуточная версия макета.

### `index-3-02.html`
Еще один вариант главной страницы. Видно, что это более ранний или экспериментальный макет:

- часть ссылок ведет на несуществующие страницы;
- часть названий и текстов содержит заглушки;
- есть отличия в навигации по сравнению с `index.html`.

### `index-3-03.html`
Еще одна вариация главной страницы. Близка к `index-3.html`, но также содержит неполные ссылки и тестовые элементы.

### `news01.html`
Страница списка новостей. Содержит:

- заголовок раздела "Новости";
- список новостных карточек;
- изображение, заголовок, краткое описание, дату, источник и теги;
- ссылки на полную страницу новости (`01.html`).

### `01.html`
Страница отдельной новости. Сейчас оформлена как шаблон полной статьи:

- заголовок материала;
- основное изображение;
- несколько абзацев текста;
- дата, время, источник и теги;
- тот же общий каркас шапки и футера, что и у других страниц.

### `og.html`
Страница раздела "Орбитальные группировки". Содержит:

- заголовок раздела;
- карточки направлений;
- визуальные блоки с hover-эффектами;
- ссылки на связанные подразделы.

Часть ссылок с этой страницы пока ведет на отсутствующие файлы.

### `og-list.html`
Страница "Орбитальные группировки по критериям". Особенность страницы:

- фильтр/поиск;
- многоуровневый раскрывающийся список;
- использование `jquery.treeview.js` и `jquery.treeview.css`.

Это одна из немногих страниц, где подключается дополнительный jQuery-плагин сверх стандартного набора Bootstrap.

### `rockets.html`
Страница раздела "Ракеты-носители". Сейчас это заготовка:

- есть шапка, хлебные крошки и заголовок;
- внутри показано предупреждение, что раздел в разработке;
- полноценный контент еще не заполнен.

## Структура каталогов

### Корень проекта

- `index.html` и `index-3*.html` — варианты главной страницы.
- `news01.html` — список новостей.
- `01.html` — страница отдельной новости.
- `og.html` — раздел орбитальных группировок.
- `og-list.html` — иерархический список критериев.
- `rockets.html` — раздел ракет-носителей.
- `info.txt` — локальный URL для открытия проекта.

### `dist/`
Основной каталог ресурсов проекта.

#### `dist/css/`
Стили проекта и сторонних библиотек:

- `bootstrap*.css` — Bootstrap;
- `style2.css`, `style2-main.css`, `style2-main-3.css`, `style.css` — пользовательские стили и варианты макетов;
- `headers.css`, `features.css`, `product.css`, `sidebars.css`, `navbar-fixed.css`, `sign-in.css` — дополнительные стили блоков;
- `font.css` — подключение шрифтов;
- `jquery.treeview.css` — стили древовидного списка;
- `c3.css` — стили для графиков C3.

#### `dist/js/`
JavaScript-библиотеки и вспомогательные скрипты:

- `bootstrap.bundle.min.js` — Bootstrap с Popper;
- `color-modes.js` — переключение/поддержка темы;
- `masonry.pkgd.min.js` — Masonry layout;
- `jquery.min.js` — jQuery;
- `jquery.treeview*.js` — дерево категорий;
- `fslightbox.js` — lightbox;
- `lazysizes.min.js` — отложенная загрузка изображений;
- `c3.js`, `d3-5.8.2.min.js` — графики;
- `main.js`, `main22.js`, `script.js`, `index.js` — локальные скрипты/заготовки.

#### `dist/img/`
Основные изображения проекта:

- иллюстрации для карточек и новостей;
- SVG-схемы;
- фоновые и вспомогательные картинки;
- несколько дублирующих или резервных файлов с пометками `копия`.

#### `dist/fonts/`
Шрифты, включая семейство Golos и шрифты Bootstrap Icons.

### `icons/`
Большой локальный набор SVG-иконок.

### `img/`
Небольшой дополнительный набор изображений и SVG, используемых в интерфейсе.

## Как запустить

### Вариант 1
Открыть файл `index.html` напрямую в браузере.

### Вариант 2
Поднять локальный статический сервер и открыть главную страницу по адресу вроде:

`http://localhost/site/index.html`

Если проект разворачивается в другой папке, путь нужно скорректировать.

## Особенности текущего состояния

Проект выглядит как макет или демонстрационный стенд, а не как полностью завершенный сайт. В репозитории есть несколько признаков этого:

- несколько версий одной и той же главной страницы;
- повторяющиеся файлы стилей и изображений;
- тестовые тексты и заглушки;
- часть разделов не заполнена;
- часть ссылок ведет на отсутствующие страницы.
